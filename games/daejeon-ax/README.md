# 대전 AX(Again eXpo) 2026 — 모션 인식 3D 운석 피하기

몸을 좌우로 움직여 운석을 피하는 90초짜리 웹 데모입니다. 설치 없이 링크/QR로 접속해 노트북(웹캠)과
스마트폰(전면 카메라)에서 바로 플레이합니다. 카메라가 없거나 거부되어도 키보드·터치·기울이기로 같은
게임을 끝까지 할 수 있습니다.

- 스택: Vite + TypeScript + Three.js (프레임워크 없음), MediaPipe Pose Landmarker(lite)
- 카메라 영상은 기기 안에서만 처리하며 전송·저장하지 않습니다. 분석 도구·외부 스크립트·CDN 없음.
- 최고 기록만 `localStorage`(`daejeon-ax-2026.best`)에 저장합니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (같은 Wi-Fi의 폰에서 접속하려면 터미널에 뜨는 Network 주소 사용)
npm test           # 단위 테스트 (충돌, 스폰 패턴의 피할 길 보장, 난이도 곡선 등)
npm run build      # 타입 검사 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 확인
```

> 카메라는 **HTTPS 또는 localhost** 에서만 동작합니다. 폰에서 `http://192.168.x.x` 로 열면 카메라 버튼이
> 비활성화되고 터치/기울이기로만 플레이됩니다. 폰에서 카메라까지 보려면 아래처럼 배포한 주소로 여세요.

포즈 모델과 WASM은 `public/mediapipe/` 에 들어 있어 같은 출처에서 서빙됩니다(행사장 네트워크 대비).
`@mediapipe/tasks-vision` 버전을 올렸다면 `npm run setup:pose` 로 다시 복사하세요.

## 배포

정적 사이트입니다. `dist/` 폴더를 HTTPS 호스팅에 그대로 올리면 됩니다.

**Vercel**

```bash
npx vercel          # 처음 한 번: 프로젝트 연결 (Framework: Vite 자동 인식)
npx vercel --prod   # 배포
```

또는 Git 저장소를 Vercel에 연결하면 됩니다(Build: `npm run build`, Output: `dist`).
`public/mediapipe/` 의 모델(5.8MB)·WASM(14.7MB)도 **저장소에 함께 커밋**해야 합니다.

**그 외(Netlify, Cloudflare Pages, GitHub Pages, 사내 서버)**: `npm run build` 후 `dist/` 업로드.
`base: './'` 로 빌드하므로 하위 경로(`https://example.com/ax/`)에 올려도 동작합니다.
서버가 `.wasm` 을 `application/wasm` 으로 내려주는지만 확인하세요.

### 스테이지 모드: 대전역에서 출발하는 대전 여행

한 판은 스테이지 12개, 스테이지 하나는 18초로 전체 3분 36초입니다. 마지막 중촌동은 행사 콘셉트에 맞춘 보너스 최종 스테이지입니다.

| # | 스테이지 | 특징 |
| --- | --- | --- |
| 1 | 대전역 | 튜토리얼: 운석이 하나씩 느슨하게 |
| 2 | 으능정이 스카이로드 | 네온 피버(대전 피버로 시작), 튀김소보로·꿈돌이 라면 |
| 3 | 성심당 | 빵지순례: 10초 동안 빵이 쏟아짐 |
| 4 | 대흥동 | **보스 · 소용돌이 운석**, 두부두루치기 |
| 5 | 엑스포다리 · 갑천 | 갑천 파도, 소국밥·오징어두루치기 |
| 6 | 한밭수목원 | 낙엽바람(옆으로 밀림), 국밥 회복 |
| 7 | 한빛탑 | **보스 · 엑스포 우주운석**(레이저), 넘기면 한빛탑 스타파워 |
| 8 | 유성온천 | 온천 안개(외곽 수증기), 회복 음식 |

**음식 9종** — 평균 15초마다 안전한 길 위에 나오고, 먹으면 가게·음식 이름과 능력이 화면에 뜹니다.
고리가 둘러져 있어 운석과 구분되며 고리 색으로 희귀도를 나타냅니다(금색 흔함 / 파랑 희귀 / 분홍 두 겹 전설).

| 음식 | 효과 | 지속 | 희귀도 |
| --- | --- | --- | --- |
| 성심당 튀김소보로 | 점수 2배 | 8초 | 흔함 |
| 성심당 딸기시루 | 무적 + 운석이 별로 바뀜 | 6초 | 희귀 |
| 오씨칼국수 물총칼국수 | 운석 속도 35% 감소 | 6초 | 흔함 |
| 진로집 두부두루치기 | 충돌 1회 방어(1회분만 저장) | 쓸 때까지 | 희귀 |
| 원조태평소국밥 소국밥 | 하트 1칸 회복(최대 체력까지) | 즉시 | 흔함 |
| 오문창순대국밥 | 피격 후 무적 시간 2배 | 8초 | 희귀 |

음식 모형은 기본 도형으로 만든 고유한 3D 아이콘이며 제품 포장·상표·로고는 재현하지 않습니다.
같은 음식을 또 먹으면 시간만 다시 채워지고 효과가 겹쳐 커지지 않습니다.

**돌발 이벤트 8종** — 시작 조건·경고·지속·쿨다운·보스전 해제 여부를 `src/game/config/events.ts` 의 데이터로 관리합니다.
한 번에 한 종류만 켜지고, 보스전에 들어가면 대전 피버를 뺀 나머지는 중단됩니다.

| 이벤트 | 내용 |
| --- | --- |
| 대전 피버 | 피버 게이지가 가득 차면 8초 동안 점수 2배(음악이 빨라지고 불티가 날림) |
| 운석 폭풍 | 1.5초 경고 뒤 7초 동안 한 줄만 남기고 모두 막힌 웨이브 |
| 빵지순례 | 10초 동안 웨이브마다 빵 |
| 중력 이상 | 운석이 곡선으로 휘어 들어옴 |
| 갑천 파도 | 운석이 일정한 기울기로 비스듬히 들어옴 |
| 유성온천 안개 | 화면 양옆 외곽에 수증기(가운데 시야는 가리지 않음) |
| 별똥별 잭팟 | 8초 동안 별 조각 점수 3배, 웨이브마다 별 |
| 한빛탑 스타파워 | 한빛탑 보스를 넘기는 순간 남은 운석이 모두 별로 바뀜 |

휘어 오는 운석은 멀리서만 옆으로 벗어나 보이고 닿는 순간에는 반드시 제 줄에 옵니다. 별·음식이 놓인 줄이 언제나 안전한 줄입니다.

**보스 3종** — 공격 버튼 없이 좌우 회피만으로 넘깁니다. 위험 구역은 공격 1초 이상 전에 보이고 안전 구역이 항상 남습니다.

| 보스 | 패턴 |
| --- | --- |
| 소용돌이 운석 | 열린 줄이 한 칸씩 돌아가는 나선 무늬 + 휘어 들어오는 운석 |
| 엑스포 우주운석 | 왼쪽·오른쪽을 번갈아 쏘는 레이저(경고 띠가 먼저 보임), 반대쪽은 안전 구역 |
| 우주대왕운석(최종) | 소용돌이 + 곡선 이동 + 레이저 |

**점수** — 운석 하나를 피할 때마다 100점, 연속으로 피하면 10개마다 배율이 0.5씩 올라 최대 3배(맞으면 초기화).
별 조각 50점, 음식 100점, 스테이지 클리어 500점, 보스 클리어 1,000점, 생존 1초당 10점.

**그 밖에**

- 숨 고르기: 스테이지가 바뀌면 2.5초 동안 새 운석이 나오지 않습니다.
- 스테이지 안내: 스테이지·보스·이벤트·음식·완주마다 색이 다른 타이틀 카드가 화면에 찍히듯 나옵니다(글꼴 파일 없이 CSS 로만).
- 결과 화면: 관광 스탬프(지나온 여행지 수), 먹은 음식 수, 난이도. 최종 보스를 넘기면 축제 불꽃 피날레.
- 진행 상태: `world.phase` 가 `PLAYING` / `EVENT` / `BOSS` / `TRANSITION` / `GAME_OVER` 중 하나를 돌려줍니다.
- 카메라 끊김: 0.5초 놓치면 멈추고(그동안 입력은 마지막 위치로 고정), 다시 잡히면 2초 동안 맞지 않습니다.
- 효과 줄이기: 왼쪽 아래 ✨ 버튼. 화면 흔들림·깜빡임·불꽃을 끕니다(기기의 "동작 줄이기" 설정을 따라 자동으로 켜짐).

| `bendChance` | 0 | 0.15 | 0.3 | 평소 웨이브가 휘어 들어올 확률 |
| `spacingJitter` | 0 | 0.25 | 0.4 | 웨이브 간격이 들쭉날쭉한 정도(박자를 외울 수 없게) |
| `starChance` / `foodEvery` | 0.6 / 1 | 0.4 / 1.3 | 0.25 / 1.7 | 별 조각이 나올 확률 / 음식 간격 배율(클수록 드묾) |
| `shieldCooldownSec` | 10 | 16 | 24 | 보호막을 다시 쓸 때까지 |

너무 어렵거나 쉬우면 위 표의 값만 고치면 됩니다. 어떤 값을 넣어도 안전한 줄은 남습니다(아래 테스트가 확인).

모든 장치는 기존 웨이브·안전 레인 구조 위에 얹혀 있어 "항상 피할 길이 있다"는 보장이 유지됩니다
(`npm test` 가 난이도 3종 × 레인 2종에서, 능력을 모두 끈 봇이 한 번도 맞지 않고 완주하는지 확인합니다).

설정 위치:

| 파일 | 내용 |
| --- | --- |
| `src/game/config/stages.ts` | 여행지 순서·이름·안내 문구·보스·예정 이벤트·바람·나오는 음식 |
| `src/game/config/items.ts` | 음식 9종의 가게·이름·능력·지속 시간·희귀도, 평균 등장 간격 |
| `src/game/config/events.ts` | 이벤트 8종의 시작 조건·경고·지속·쿨다운, 피버 게이지가 차는 양 |
| `src/game/config/presets.ts` | 난이도 3종(속도, 운석 간격, 밀도, 판정 크기, 돌발 요소, 보호막 쿨다운) |
| `src/config.ts` | 스테이지 길이, 숨 고르기, 레이저, 점수(회피·콤보·클리어) |

스테이지 수나 길이를 바꾸면 마지막 스테이지에서 난이도가 한계에 닿도록 `presets.ts` 의 `speedStep`·`gapDecay`·`densityStep` 도
함께 조정하세요(테스트가 확인합니다).


### 배경: 대전 관광 테마 우주

스테이지마다 그 여행지의 행성 **하나만** 나옵니다. 스테이지가 시작되면 멀리 작게 보이다가 진행될수록 다가와 커지고,
스테이지가 끝날 때 화면 옆으로 지나갑니다(좌우는 스테이지마다 번갈아). 행성은 12개입니다: 대전역, 으능정이 스카이로드,
성심당(빵), 대흥동, 엑스포다리+갑천, 한밭수목원, 한빛탑, 유성온천, 장태산, 계족산 황톳길, 대청호, 중촌동 축제.
가운데 플레이 영역은 비워 두고, 글자·간판·로고는 쓰지 않습니다. 타이틀·선택 화면에서는 행성을 하나씩 돌아가며 보여 줍니다.

- 게임 로직과 분리된 모듈입니다. `render/backdrop.ts` 가 `config.ts` 의 `scenery` 와 스테이지 목록의 `planet` 만 읽습니다.
- 행성은 Three.js 기본 도형을 합친 메시라 행성 하나가 드로우콜 1~2개이고, 외부 모델 파일은 쓰지 않습니다.
  한 번에 하나(바뀌는 순간에만 둘)만 그리므로 모바일 부담이 이전보다 작습니다.
  반복되는 축제 등불은 InstancedMesh 하나, 불꽃은 기존 파티클 풀을 씁니다.
- 어느 스테이지에 어느 행성이 나올지는 `src/game/config/stages.ts` 의 `planet` 으로 정합니다.
- 새 행성은 `render/planets.ts` 에 함수를 하나 만들어 `RECIPES` 에 등록하고, `config.ts` 의 `PlanetType` 에 추가합니다.

난이도와 "피할 길 보장" 규칙을 바꾼 뒤에는 `npm test` 로 확인하세요. 테스트는 안전 레인을 따라가는 봇이
180초 동안 한 번도 맞지 않는지, 가만히 서 있어도 처음 10초는 살아남는지를 검사합니다.

## 구조

```
src/
  main.ts        진입, 상태 머신(title → select → permission → calibrate → countdown → play → result)
  config.ts      조정값 전부
  game/          world, player, meteors(스폰 패턴), pickups, collision, difficulty  ← 렌더·입력과 무관, 단위 테스트 대상
    config/      stages(여행지·보스), items(음식 9종), events(이벤트 8종), presets(난이도 3종)
    items/       음식 등장과 효과
    events/      돌발 이벤트 관리자(한 번에 하나, 쿨다운, 보스전 해제)
    boss/        보스 공격(레이저, 좌우 반복 공격)
    progression/ 진행 상태(PLAYING·EVENT·BOSS·TRANSITION·GAME_OVER)
  input/         pose(MediaPipe), tilt, touch, keyboard → 공통 { x: -1~1, shield }, filter(One Euro)
  render/        scene, backdrop(배경: 스테이지별 행성·등불·불꽃), planets(대전 명소 행성 12종 조리법),
                 character(자세·애니메이션), stagefx(음식·레이저·보스·낙엽 연출), starfield, particles, quality(적응형), fit(화면비별 카메라)
  ui/            화면 전환, HUD
  audio/         Web Audio 합성 효과음 + 배경음악(src/assets/audio/bgm.mp3 반복 재생, 파일이 없어도 게임은 동작)
  assets/        characters(로더: glb → png → 코드 모델), figure(꿈돌이), rocket(로켓), build(공용 도구)
public/mediapipe/  포즈 모델(.task)과 WASM
```

조작: 카메라(몸 좌우 이동, 양손 들기=보호막) / 키보드(← → 또는 A D, 스페이스=보호막) /
터치(좌우 드래그, 두 손가락=보호막) / 기울이기.

## 실기기 점검 목록

배포한 HTTPS 주소로, 폰을 세워 두고 1~2m 떨어져 상반신이 보이는 상태에서 확인합니다.

**공통 (iOS Safari, Android Chrome 각각)**

- [ ] QR/링크로 접속 → 로딩 → 타이틀까지 걸리는 시간 (LTE와 Wi-Fi)
- [ ] "시작" 후 효과음·배경음이 나고 음소거 버튼이 동작
- [ ] 카메라 권한 창이 뜨고, 허용 시 거울처럼 보이는 미리보기와 초록 점(스켈레톤)이 표시
- [ ] 가운데 서면 2초 뒤 자동으로 카운트다운으로 넘어감
- [ ] 몸을 오른쪽으로 움직이면 캐릭터도 **화면 오른쪽**으로 (거울 방향), 지연이 체감되지 않음
- [ ] 살짝만 기울여도 화면 끝까지 감 (`pose.rangeShoulders`)
- [ ] 화면 밖으로 나가면 1초 뒤 "화면 안으로 들어와 주세요", 돌아오면 자동 재개
- [ ] 두 사람이 서면 가운데 사람만 따라감
- [ ] 양손 들기 보호막이 오작동 없이 동작 (불안하면 `pose.enableShield: false`)
- [ ] 세로·가로 모두에서 운석이 화면 안에서 다가오고 UI가 잘리지 않음(노치·홈 인디케이터 포함)
- [ ] 스크롤·핀치줌·당겨서 새로고침이 일어나지 않음
- [ ] 플레이 중 화면이 꺼지지 않음 (Wake Lock)
- [ ] 홈으로 나갔다 돌아오면 일시정지 → 카메라가 다시 켜지고 재개
- [ ] 카메라 거부 → 조종 방식 화면의 "손으로 조종"으로 드래그·기울이기 조작
- [ ] 난이도·조종 방식·보정 화면의 "뒤로"로 한 단계씩 돌아감(PC 는 Esc, 메뉴는 방향키·엔터로도 조작)
- [ ] 한 판이 60~90초쯤에 끝나는지, 3~5명에게 시켜 보고 `difficulty.*` 조정
- [ ] 2~3판 연속 플레이 후에도 프레임이 30fps 이상 유지(발열)
- [ ] 30초 방치하면 타이틀로 돌아감
