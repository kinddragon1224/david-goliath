# 캐릭터 에셋 슬롯

기본 꿈돌이는 코드로 만든 3D 모델입니다(`src/assets/figure.ts`, 로켓은 `src/assets/rocket.ts`).
외부에서 만든 모델로 바꾸려면 이 폴더에 아래 이름으로 파일을 넣고 다시 빌드하면 됩니다. 코드 수정은 필요 없습니다.

| 캐릭터 | 3D 모델 (우선) | 이미지 (차선) |
| --- | --- | --- |
| 꿈돌이 | `kkumdori.glb` | `kkumdori.png` 또는 `kkumdori.webp` |

우선순위: **glb → png/webp → 코드로 만든 모델**. 파일을 읽지 못하면 다음 순서로 자동으로 넘어갑니다.

## GLB 규격

- 정면이 +Z, 위가 +Y. 크기와 위치는 자동으로 맞춥니다(높이 약 1.05, 바닥이 로켓 윗면에 닿게).
- **캐릭터만 있는 모델**이면 게임이 로켓 위에 앉혀 줍니다.
  로켓까지 포함된 모델이면 `src/config.ts` 의 `character.rocket` 을 `false` 로 바꿔 기본 로켓을 끄세요.
- Draco/Meshopt 압축은 지원하지 않습니다. 압축 없이 내보내고 텍스처 포함 2MB 이하를 권장합니다.
- 통짜 모델로 취급합니다. 대기 흔들림·좌우 기울기·피격 떨림·종료 시 뒤돌아 처지는 동작은 모델 전체에 적용되고,
  머리·팔·더듬이가 따로 움직이는 동작은 코드로 만든 모델에서만 나옵니다.

## 이미지 규격

배경이 투명한 이미지, 긴 변 512px 이상. 항상 카메라를 바라보는 평면으로 표시되므로 입체감은 없습니다.

## 캐릭터 추가

`src/config.ts` 의 `CHARACTERS` 와 `src/assets/characters.ts` 의 `procedural` 에 한 줄씩 추가하면
선택 화면의 버튼과 배치가 자동으로 늘어납니다.
